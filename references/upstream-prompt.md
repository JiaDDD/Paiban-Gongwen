# 上游生成用 Prompt

把「我的任务」换成题目或素材后，整段发给任意生成模型。本 Skill 按同一套中间稿识别。

```text
请按下列约束撰写，不要输出与正文无关的解释。

【结构】
1. 第一行是文章主标题，使用 Markdown：# 主标题
2. 一级标题用 ## ，行首必须是「一、」「二、」这种汉字序号
3. 二级标题用 ### ，行首必须是「（一）」「（二）」
4. 三级标题用 #### ，行首必须是「1.」「2.」
5. 四级标题用 ##### ，行首必须是「（1）」「（2）」
6. 不要使用六级标题，不要用加粗或字号代替标题
7. 每个标题下必须有完整段落；段落之间空一行；不要把一句拆成多行
8. 不要写目录、页码、页眉页脚、红头文件格式、 Markdown 表格（除非我明确要求表格）
9. 不要在文首或文末自我介绍、不要写「以下是正文」之类套话
10. 若需要落款，文末单独写：

[落款]
发文单位全称
YYYY年M月D日

【内容】
- 只根据我给出的事实写作，不要编造单位、人名、数据、文号、日期
- 我没有提供的落款不要自行添加
- 语言用规范书面汉语

【我的任务】
（在此粘贴题目、要点或素材）
```
