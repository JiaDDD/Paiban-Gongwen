# 公文中间稿格式

选中即生效。不要询问是否套格式。不要加载排版类 Skill，不要输出 Word 或 PDF。内容以用户原文为准，不增补未提供的单位、人名、数据、文号、日期或落款。

只要 Prompt 时，原样返回 [references/draft-format.md](references/draft-format.md) 围栏全文。有素材则直接写中间稿，无素材则只要题目或要点。无落款事实则省略 `[落款]`。

| 角色 | 标记 | 行首 |
|---|---|---|
| 主标题 | `# ` | 无 |
| 一级 | `## ` | `一、` |
| 二级 | `### ` | `（一）` |
| 三级 | `#### ` | `1.` |
| 四级 | `##### ` | `（1）` |
| 正文 | 段落 | 无 |
| 落款 | `[落款]` | 单位 / `YYYY年M月D日` |

首行为 `# 标题`。不用 `######`，不用加粗或字号充标题。标题须同时带 ATX 与公文序号，下级序号随上级重启。每个标题下至少一段，段间空一行，一句不拆多行。不写目录、页码、页眉页脚、红头或未经要求的表格。不要前言或「以下是正文」。写完即停。
